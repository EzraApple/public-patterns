# Investigation recovery and model comparison — September 9, 2026

## Production audit

The August 25–September 7 attempt ledger contained 18 distinct non-noise
candidates: eight were attempted and all failed; ten were never selected.
The latest daily summaries undercount those failures because later attempts
can replace a failed selection with another candidate or `not_ready`.
A lack of articles in this interval therefore does not demonstrate a lack of
worthwhile stories. One-candidate selection and readiness behavior remain
separate follow-up work.

After the DeepSeek balance was replenished, the August 26 Mission Bay traffic
stop and August 29 Chinatown private-graffiti cases were deliberately replayed
through the production Workflow. Both exhausted their retry with a terminal
OpenCode `Transport` failure near five minutes. No new article resulted.

The saved August 8 Bayview draft was briefly recovered, then removed after
full-text comparison showed that the existing August 17 story already covers
its two-intersection concentration. The private recovery is marked `discard`;
the original archive remains intact. Distinct dates and slugs are insufficient
proof of a new finding. The feed returned to four articles.

## Confirmed execution defects

- The pinned July OpenCode CLI let Bun's default five-minute HTTP deadline kill
  its long-running event stream. The [upstream August 19 fix](https://github.com/anomalyco/opencode/commit/d5bf8799c0e0706ec604324d9abef45cfae4dcd0)
  disables that deadline. The investigator now pins the npm `latest` release
  `@opencode-ai/cli@0.0.0-beta-17823`, which includes it. Live investigations
  continued beyond five minutes on that binary. The 12-minute sandbox and
  15-minute Workflow step limits remain intact.
- Exact DataSF queries returned 403 from `data.sfgov.org` and 200 from
  `data.sf.gov` on this date. The ingestion gateway and generated citations
  now use the working host. This is a dated observation, not a claim about an
  officially announced permanent redirect.
- The local paid-eval client also had an independent five-minute Undici
  response-header deadline despite a longer abort signal. Its long POST now
  uses Node's HTTP client with an explicit 16-minute abort.
- A utility under OpenCode's plugins directory was being loaded as a plugin
  without a default export. It now lives outside that auto-loaded directory.
- Failure classification now reads the terminal structured error before
  considering incidental tool output. Failed runs retain bounded, redacted
  unsubmitted drafts for diagnosis; these are never completed checkpoints.

## Duplicate controls

Publication uses an atomic D1 guard against a second slug for the same source,
day, kind, and area, including a replay with a different investigation ID.
Revisions under the existing slug remain possible. A real Worker/D1 integration
regression exercises this behavior.

New investigations receive up to 20 current articles, prioritizing the same
area, as full-text editorial context. The agent must discard an already-covered
finding unless a verified development materially changes it. The
`bayview-already-covered-2026-08-08` fixture tests cross-date overlap.
This is a bounded model check, not a semantic uniqueness guarantee; manual
backfills still require a final comparison with the current feed.

## Comparison design

All four published articles now have fixtures extracted from their original
successful R2 archives. This coverage was not automatic or complete before
this change. Expected outcomes, published slugs, and provenance labels stay
outside agent input. The original Haight traffic-stop negative control checks
that higher publication yield does not simply mean a looser story threshold.

Both models use maximum reasoning effort and the same 12-minute execution
budget. Inputs are frozen, but source queries are live; source drift and
editorial quality require human review in addition to sparse phrase checks.
Local evals do not publish. Infrastructure failures before model execution are
reported separately from model outcomes.

## Pricing and scope

On the [official pricing page](https://api-docs.deepseek.com/quick_start/pricing/),
V4 Flash off-peak prices per million tokens are $0.007 cached input, $0.22
uncached input, and $0.66 output; Pro is $0.022, $0.66, and $1.98 respectively.
Flash is about one-third of Pro's token price, not necessarily one-third of the
cost per completed article. The comparison runs and existing 22:30/23:30 UTC
cron schedule fall outside the weekday peak windows.

The [model updates](https://api-docs.deepseek.com/updates/) identify the current
aliases as V4-Flash-0731 and V4-Pro-0813. Flash-Vision-Exp adds experimental
vision without an advantage for the current text-only case input. The
[thinking-mode guidance](https://api-docs.deepseek.com/guides/thinking_mode/)
recommends high effort for everyday agents; this comparison holds effort at max
to isolate model choice. It does not establish the best effort setting.
