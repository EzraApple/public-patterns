# Analyze a signal

Measure what the data supports and expose what it does not. A record count is
not automatically an event count, and a convenient comparison is not
automatically a valid control.

## Analysis

1. Define the unit being counted. Note likely duplicates, updates, administrative
   entries, or multiple records generated by one real-world response.
2. Use Python for timelines, distances, grouping, recurrence, or baseline
   calculations when it reduces ambiguity.
3. Match comparisons to source coverage and the relevant time-of-day,
   day-of-week, season, geography, and category when the data permits.
4. Treat a small ordered sample, the first rows returned by a query, or distant
   points included as contrast as context—not a representative control.
5. Do not spread a daily average uniformly across minutes, calculate odds, or
   use large multiplier language without a defensible model and assumptions.
   Prefer counts, ranges, and ratios over z-scores, p-values, or effect sizes
   when controls are small convenience samples.
6. Report the denominator, sample size, query window, and important assumptions
   behind every material statistic.
7. Treat identical published coordinates as the same recorded geography, not
   proof of exact physical co-location.
8. Do not merge unlinked records into one response, reporter, device, or causal
   chain. Say a pattern is compatible with an explanation unless the data links
   it explicitly.
9. For repeated target/control series, compare each target with its matching
   controls before pooling across years, seasons, or event instances.

## Interpretation

- Temporal or spatial concentration can justify triage.
- Different record types can be related, duplicated, or coincidental.
- A sequence ordered by timestamp is not an event chain.
- Do not rank one explanation above another unless the evidence distinguishes
  between them.
- If the available baseline is weak, describe the observed concentration and
  say what comparison is missing.
- Prefer a stable descriptive result over a fragile significance claim.
